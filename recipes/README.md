# Odin Recipes Collection

A multi-page recipe website built as part of **The Odin Project** curriculum. This project demonstrates core web fundamentals including semantic document structuring, inter-page linking, image handling, ingredient lists, step-by-step preparation procedures, and custom CSS page styling.

---

## 🍲 Included Recipes

1. **Classic Lasagna (`lasagna.html`)**:
   - Rich, layered Italian lasagna featuring seasoned ground beef, tomato sauce, ricotta, mozzarella, and parmesan cheese.
   - Includes custom stylesheets in `/CSS Files/lasagna.css`.

2. **Nigerian Jollof Rice (`jollofRice.html`)**:
   - Authentic, vibrant West African one-pot rice infused with slow-simmered blended bell peppers, tomatoes, onions, aromatic spices, and bay leaves.

3. **Yam Casserole (`yamCasserole.html`)**:
   - Comfort food dish combining tender yam tubers with savory vegetables and seasonings baked to perfection.

4. **Crispy Fried Potatoes (`friedPotatoes.html`)**:
   - Golden-brown skillet-fried potatoes seasoned with herbs, garlic, and cracked black pepper.

5. **Puerto Rican Coquito (`Coquito.html`)**:
   - Traditional holiday coconut beverage made with coconut milk, condensed milk, vanilla, cinnamon, and rum.
   - Styled with dedicated CSS in `/CSS Files/Coquito.css`.

---

## 🛠️ Technology & Concepts

- **HTML5 Semantic Elements**: `<h1>` through `<h3>` headers, `<p>` descriptions, `<ul>` unordered ingredient lists, `<ol>` ordered step lists, `<a>` anchor navigation, and `<img>` media embeds.
- **CSS3 Styling**: Custom color palettes, typography, card containers, and layout spacing.
- **Navigation Flow**: Clean links between individual recipe pages and home index.

---

## 🚀 How to Run

1. Open any of the `.html` files in `/recipes/` directly in a browser, or:
2. From the project root, start the server (`npm start`) and navigate to:
   ```
   http://localhost:3000/recipes/lasagna.html
   ```
   or via the shortcut route:
   ```
   http://localhost:3000/recipes
   ```
