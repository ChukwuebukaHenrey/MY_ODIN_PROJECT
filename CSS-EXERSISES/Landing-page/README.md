# Product Landing Page Project

A complete, responsive, full-page product landing page built from scratch using HTML5, modern CSS3 Flexbox layout techniques, and vanilla JavaScript for mobile navigation toggling.

---

## 🚀 Sections & Features

1. **Responsive Navigation Bar**:
   - Brand logo header.
   - Desktop navigation link list.
   - Accessible mobile hamburger menu (`aria-expanded`, animated burger icon toggle).

2. **Hero Section**:
   - High-contrast typography featuring heading, informative lead paragraph, and primary call-to-action button.
   - Side-by-side layout on desktop with fluid responsive stacking for mobile viewports.
   - Clean image wrapper.

3. **Information / Features Grid**:
   - 4-card column grid highlighting features with circular image illustrations and descriptive subtext.

4. **Testimonial Quote Banner**:
   - Stylized quote section emphasizing social proof and speaker attribution.

5. **Call-to-Action (CTA) Container**:
   - Dedicated high-visibility call-out box with bold action copy and a secondary "Sign Up" button.

6. **Footer**:
   - Clean copyright footer with attribution.

---

## 🛠️ Key Technical Practices

- **Flexbox Mastery**: Utilizes `justify-content: space-between`, `align-items: center`, `flex-wrap: wrap`, and flexible direction controls (`flex-direction: column` on mobile).
- **Responsive Web Design**: Media queries tailoring font sizes, gaps, and column orientations across mobile, tablet, and desktop screens.
- **Mobile Menu Logic**: Lightweight vanilla JavaScript event listener managing menu classes and accessible state attributes.

## 🚀 How to Run

1. Open `/CSS-EXERSISES/Landing-page/index.html` in your web browser, or:
2. From the root directory, start the server (`npm start`) and navigate to:
   ```
   http://localhost:3000/CSS-EXERSISES/Landing-page/index.html
   ```
   or via the shortcut route:
   ```
   http://localhost:3000/landing
   ```
