# Flexbox Practice Suite

A structured series of 7 progressive Flexbox exercises from The Odin Project demonstrating mastery over modern one-dimensional CSS layout design.

---

## 📋 Exercises Index

1. **`01-flex-center`**: Centering boxes horizontally and vertically with `justify-content: center` and `align-items: center`.
2. **`02-flex-header`**: Building symmetric multi-group headers with spaced navigation menus and centered branding.
3. **`03-flex-header-2`**: Advanced header design with action pills, profile avatars, and responsive alignment.
4. **`04-flex-information`**: Feature item card layout with image icons, text descriptions, and wrap control.
5. **`05-flex-modal`**: Interactive modal popup window with title header, close trigger, body text, and action buttons.
6. **`06-flex-layout`**: Full-page search engine landing layout with sticky header, centered action block, and footer.
7. **`07-flex-layout-2`**: The classic "Holy Grail" web layout with header, responsive sidebar, dynamic card grid, and footer.
