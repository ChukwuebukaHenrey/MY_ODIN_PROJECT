# Block and Inline / CSS Box Model Exercises

Hands-on exercises focusing on the CSS Box Model, element flow (block vs inline), margins, padding, borders, and container spacing.

---

## 📋 Exercises

1. **`01-margin-and-padding-1`**:
   - Focus: Applying exact margins and paddings across block `<div>` elements without modifying markup.
   - Key concepts: Margin collapse, box sizing, and vertical spacing.

2. **`02-margin-and-padding-2`**:
   - Focus: Constructing a polished card container with title hierarchy, content body spacing, and action button padding.
   - Key concepts: Component encapsulation, inner vs outer padding, and typography rhythm.
