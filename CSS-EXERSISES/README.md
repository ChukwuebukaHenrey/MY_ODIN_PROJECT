# CSS & Flexbox Foundations Exercise Series

This directory contains a progressive series of hands-on technical exercises completed as part of **The Odin Project** curriculum. Each drill addresses specific core CSS concepts, layout paradigms, selector specificity rules, and the box model.

---

## 📚 Exercise Breakdown

### 1. Cascade & Specificity
* **`01-cascade-fix/`**: Resolving CSS inheritance, selector precedence, rule order, and specificity conflicts to style paragraphs, confirmation/cancellation buttons, and nested child elements.
* **`01-css-methods/`**: Understanding external stylesheets (`<link>`), internal styles (`<style>`), and inline `style=""` attributes.
* **`02-class-id-selectors/`**: Applying styles selectively via class names (`.class`) versus unique identifiers (`#id`).
* **`03-grouping-selectors/`**: Dry code practices using comma-separated selector grouping for shared button styles.
* **`04-chaining-selectors/`**: Chaining multi-class selectors on single elements (`.avatar.proportioned` vs. `.avatar.distorted`) with custom image scaling and aspect ratios.
* **`05-descendant-combinator/`**: Targeting elements based on ancestor-descendant hierarchy using space combinators (`div p`).

---

### 2. Block and Inline / Box Model (`/block-and-inline`)
* **`01-margin-and-padding-1/`**: Visualizing CSS box model margins, paddings, and borders across stacked block elements.
* **`02-margin-and-padding-2/`**: Building realistic card containers with balanced inner padding, button alignment, and typography spacing.

---

### 3. Flexbox Suite (`/flex`)
* **`01-flex-center/`**: Perfect horizontal and vertical centering of elements using `display: flex`, `justify-content: center`, and `align-items: center`.
* **`02-flex-header/`**: Navigation header layout with distributed left links, centered logo, and right link clusters.
* **`03-flex-header-2/`**: Complex header with logo, navigation links, notification action pill, and user profile avatar.
* **`04-flex-information/`**: Multi-item product/plant feature cards with image assets, descriptions, and balanced wrapping.
* **`05-flex-modal/`**: Accessible modal dialog component featuring header icon, close button, body text, and action buttons.
* **`06-flex-layout/`**: Full-page layout template with top header, centered hero search container with input & action buttons, and sticky footer.
* **`07-flex-layout-2/`**: Classic "Holy Grail" three-section layout with top bar, responsive sidebar navigation, main card grid, and footer.

---

### 4. Full Landing Page Project
* **`Landing-page/`**: Production-ready, fully responsive product landing page with mobile hamburger drawer navigation. See [`Landing-page/README.md`](./Landing-page/README.md) for full details.
