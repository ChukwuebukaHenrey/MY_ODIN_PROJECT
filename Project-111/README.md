# MovieHive — Movie Streaming UI

**MovieHive** is a modern entertainment & movie streaming web interface designed with semantic HTML5, modern CSS3 layout patterns (Flexbox and CSS Grid), and FontAwesome iconography.

---

## 🎬 Features & UI Sections

1. **Navigation Header**:
   - Custom MovieHive brand logo and typography.
   - Interactive search bar with search icon.
   - User profile management avatar and theme toggle button.

2. **Featured Hero Showcase**:
   - High-impact backdrop styling with dark overlay.
   - Featured titles carousel/cards (e.g., *WonderLand*, *Secret Level*, *Humane*, *The Arctic Convoy*, *Lokah*, *Wednesday*).
   - Play overlay action buttons on poster hover.

3. **Continue Watching Shelf**:
   - Quick resume shelf with metadata display (*Baby Driver*, *Aladdin*, *The Martian*, *Doctor Strange*).
   - Release year, maturity ratings (e.g., `+18`, `+13`), and audio language pills (`En`, `Ru`, `Ar`, `Esp`).
   - "See more" direct link navigation.

4. **Coming Soon / Trending Releases**:
   - Curated preview list for upcoming movie titles (*Bat Man*, *Damsel*, etc.).
   - Local asset integration with high-resolution poster artwork.

---

## 🛠️ Technologies Used

- **HTML5**: Semantic tags (`<section>`, `<nav>`, `<main>`, `<article>`) for accessible content hierarchy.
- **CSS3**: Custom properties, gradient overlays, card hover transitions, responsive containers, and modular layout rules.
- **FontAwesome (v7)**: Icons for search, play buttons, profile icons, and directional arrows.
- **Google Fonts**: Curated display typography (`Inter`, `Anton`, `Oswald`, `Raleway`, `Roboto Condensed`).

## 🚀 How to Run

1. Open `/Project-111/index.html` in your browser, or:
2. From the project root, run `npm start` and visit:
   ```
   http://localhost:3000/Project-111/index.html
   ```
   or via the shortcut route:
   ```
   http://localhost:3000/moviehive
   ```
